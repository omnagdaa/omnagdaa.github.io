# omnagdaa.github.io

Hugo static site (`hugo.yaml`, `content/`, `archetypes/`), deployed via GitHub Pages.

## UI work

Follow the Vercel Web Interface Guidelines in
`.claude/commands/web-interface-guidelines.md` when writing or changing any
templates, partials, layouts, CSS, or JS — not only when reviewing. The same
file is invokable as `/web-interface-guidelines <file-or-pattern>` to audit
existing files.

Highest-value rules for this site: semantic HTML over ARIA, visible
`:focus-visible` states, explicit `width`/`height` on images, `loading="lazy"`
below the fold, `prefers-reduced-motion` honored, typographic `…` and curly
quotes, and `color-scheme` set for dark mode.
