I build the analysis software I wanted to exist. Most of my work sits where
security engineering meets DevOps: memory forensics, mobile application
security, and the infrastructure automation that keeps the tooling shipping.

The throughline is that good analysis tools should not require memorising
command-line syntax. [DumpScope](/projects/dumpscope/) came out of that —
Volatility3 is excellent and its interface is a wall, so I put a wizard in
front of it.

## What I work on

**Memory forensics.** Acquisition and analysis of memory images, Volatility3
plugin workflows, and building interfaces over them.

**Mobile security.** Android and iOS application security testing — static and
dynamic analysis, instrumentation, and traffic interception.

**DevOps and infrastructure.** CI/CD pipelines, containerised build and test
environments, and the automation that turns a local script into something a
team can run.
